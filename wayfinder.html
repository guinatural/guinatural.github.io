01

O que o Wayfinder faz

O Wayfinder monitora a infraestrutura AWS 24/7 usando o AWS Config como motor de avaliação. Quando um recurso viola uma regra de compliance, o EventBridge roteia o evento para uma Lambda que enriquece o achado com artigo LGPD correspondente, dispara alerta via SNS e, para violações elegíveis, executa remediação automática com guardrails de segurança.

Todo evento — detecção, notificação e remediação — é registrado no CloudTrail, que vai para um bucket S3 com Object Lock em modo COMPLIANCE, tornando os logs imutáveis por 5 anos. Esses logs são consultáveis com SQL via Athena.

// Fluxo principal do Wayfinder AWS Config (37 regras: 23 managed + 14 WAYFINDER-*) │ recurso muda de configuração ▼ EventBridge (roteamento por severidade e tipo) │ ▼ Lambda: compliance-evaluator ├─ enriquece: artigo LGPD, severidade, dados do recurso ├─ publica métrica no CloudWatch ├─ envia alerta via SNS (email + Slack) └─ se elegível → invoca Lambda: auto-remediation ├─ guardrail: remediation-exempt tag? ├─ guardrail: tentativas < 3 na última hora? └─ executa ação: S3 / CloudTrail / SG CloudTrail → S3 Object Lock (COMPLIANCE, 5 anos) └─ Glue Crawler → Athena └─ relatório semanal via Lambda: audit-reporter

03

Decisões de arquitetura (ADRs)

Cada decisão relevante tem um ADR. Não uso ADR como burocracia — uso para rastrear por que escolhi algo e quais alternativas descartas.

ADR-001
Terraform, não CDK
CDK gera CloudFormation por baixo. Quero entender o que está sendo implantado, não o que uma abstração gera. Terraform também aparece mais em vagas PJ no Brasil.
ADR-002
Event-driven, não polling agendado
Lambda a cada 5 minutos custaria mais e detectaria violações com até 5 minutos de atraso. EventBridge reage à mudança real em segundos.
ADR-003
S3 Object Lock COMPLIANCE (não GOVERNANCE)
CFM 1821/2007 exige prontuários por 20 anos. GOVERNANCE mode pode ser bypassado por admins. COMPLIANCE mode é o único que garante imutabilidade legal.
ADR-004
Remediação seletiva, não total
Quase construí auto-remediação para tudo. Mas: e se a Lambda remove uma permissão que um sistema médico depende? Médico não loga. Novo incidente. Matriz de reversibilidade decidiu.
ADR-005
VPC Endpoints, não NAT Gateway
Lambdas chamam KMS, CloudTrail e Config constantemente. Com NAT, esse tráfego sai pela internet pública antes do TLS. Com VPC Endpoints, fica dentro da rede AWS. Para dados de saúde, a escolha certa.
ADR-009
IAM OIDC no CI/CD, não access keys
Access keys estáticas no GitHub geram o mesmo problema que o WAYFINDER-007 detecta: credenciais em lugar errado. OIDC: token temporário emitido por STS no momento do deploy, sem chave armazenada.

O que aprendi construindo isso

  • 🔐IAM é a base de tudo. A maioria dos incidentes de segurança não começa por falha de criptografia — começa por permissão excessiva. O WAYFINDER-005 existe porque 12 roles com AdministratorAccess em produção é um risco maior do que qualquer S3 sem KMS.
  • ⚡Event-driven não é "mais moderno", é mais correto para este problema. Polling a cada 5 minutos detectaria o incidente VitaCore em até 5 minutos. EventBridge detecta em segundos. A diferença entre as duas abordagens é mensurável em reais de prejuízo.
  • 🧪Testar código que chama AWS é difícil sem moto. Aprendi que dois handlers com o mesmo nome em sys.modules se sobrepõem. A solução com importlib.util.spec_from_file_location foi mais valiosa do que a feature em si.
  • 📄ADRs não são burocracia. Quando decidi não auto-remediar IAM, escrever o ADR-004 me forçou a articular o raciocínio. Duas semanas depois, reli e ainda concordei com a decisão. Isso tem valor.
  • 💰Custo de prevenção vs custo do incidente. O ambiente de governança custa ~R$ 6.200/ano. O incidente de março custou R$ 2,1 milhões. O ROI de 340× não é marketing — é aritmética simples que qualquer CTO precisa entender.
