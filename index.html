Projeto Principal

Projeto em destaque
Wayfinder Cloud
Projeto de governança cloud · cenário VitaCore Health · AWS + Terraform + Python
Em desenvolvimento
O problema que este projeto resolve

VitaCore Health é um cenário hipotético de portfólio, criado para discutir exposição de dados sensíveis e controles de governança. Não descreve um incidente real, uma sanção aplicada ou um resultado medido do Wayfinder.

Projeto de portfólio que modela governança cloud orientada a eventos: avaliação de conformidade com AWS Config, roteamento com EventBridge e tratamento de achados em Lambda. O repositório documenta controles, opções de remediação e trilha de auditoria; não há afirmação de operação contínua, implantação em produção ou desempenho medido.

08

Sobre

Terminei o treinamento AWS na Escola da Nuvem e fiz 23 labs práticos. Cada lab ensinou um serviço. Mas nenhum deles me pediu para combinar tudo com uma razão real por trás.

"Então construí algo que me forçasse a tomar decisões reais de arquitetura — não seguir um tutorial."

VitaCore Health é um cenário hipotético para discutir riscos de exposição de dados sensíveis e opções de governança em nuvem. O Wayfinder Cloud é um exercício técnico de portfólio, não um relato de incidente real nem de implantação em uma organização.

O que me diferencia não é ter feito os labs — todo mundo faz. É ter entendido por que cada serviço existe e quando ele é a escolha certa. As decisões e os materiais técnicos disponíveis podem ser consultados no repositório do projeto.
