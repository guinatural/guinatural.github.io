Holocron Sentinel

Capstone AWS re/Start: prova de conceito de agente de auditoria AWS acionado sob demanda, com ferramentas Boto3 e raciocínio via Amazon Bedrock (Strands). Não é o case de governança por eventos do Wayfinder.

Contexto: Escola da Nuvem · capstone Stack: Python · Boto3 · Bedrock · Strands Status: Prova de conceito; consulte o repositório para o estado atual AgentCore capstone: Holocron-Sentinel-AWS-AgentCore ↗

A necessidade

Uma revisão pontual de uma conta AWS envolve olhar configurações diferentes de S3, IAM e EC2. O capstone explora como reunir essas verificações quando um consultor solicita uma auditoria, em vez de tratar cada scanner como uma tarefa isolada.

A resposta da prova de conceito

O usuário envia um pedido; Strands e Bedrock podem selecionar quatro ferramentas Boto3 e compor um relatório. O fluxo é sob demanda e termina em revisão humana — não é vigilância contínua nem um serviço multi-tenant comprovado em produção.

Estado real: o repositório do capstone apresenta a PoC e seus scanners. Uma chave de sessão com tenant_id não demonstra autorização nem isolamento entre clientes. Este projeto é separado do Wayfinder.

02

Decisões que um recrutador pode testar

D1
Tools, não só texto
Cada scanner é um @tool Strands com Boto3. O modelo chama a API da conta, não inventa o achado.
D2
Chave de sessão por tenant
A chave inclui tenant_id, mas isso não prova isolamento entre clientes. Autorização, validação de caminhos, permissões do armazenamento e proteção dos dados também precisam ser avaliadas.
D3
PoC honesta
É uma prova de conceito, não um SaaS multi-tenant implantado em produção. A chave de sessão por tenant é apenas parte do desenho e não constitui garantia de isolamento.
D4
Dois produtos, um portfólio
Holocron explora acionamento sob demanda; Wayfinder explora avaliação orientada a eventos. São projetos e repositórios distintos.
