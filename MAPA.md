## Projetos e repositórios

| Projeto | Papel no portfólio | Repositório |
|---|---|---|
| Wayfinder Cloud | Arquitetura de governança AWS orientada a eventos; cenário hipotético VitaCore Health. | <https://github.com/guinatural/wayfinder-cloud> |
| Holocron Sentinel / AgentCore | Capstone de agente de auditoria sob demanda. | <https://github.com/guinatural/Holocron-Sentinel-AWS-AgentCore> |
| Holocron Sentinel V2 | Repositório independente do capstone AgentCore. | <https://github.com/guinatural/Holocron-Sentinel-Startup-V2> |
| DocuSmart | Projeto Hack2Hire de processamento de documentos. | <https://github.com/guinatural/docusmart-motor-strands> |

Wayfinder e Holocron são projetos distintos: um explora governança orientada a eventos; o outro, um agente acionado sob demanda. O V2 é um repositório separado do capstone AgentCore.
